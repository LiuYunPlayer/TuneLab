# 分组「+」菜单与下拉搜索 · 测试用例

> 范围：三处「从选项树里挑一项」的入口统一用同一个弹出菜单——下拉框（ComboBox）、变长列表的 `+`（ListConfig）、
> 键控容器的 `+`（ExtensibleObjectConfig）。本次新增：`+` 候选可分组（多级子菜单），叶子数 ≥ 10 时菜单顶部出现搜索框。
> 另修：带分组的下拉在命令面（agent/CLI）里列不出选项、写不进值。
> 下拉的值/显示分离、非法值琥珀呈现、条件面板重算等已由 `COMBOBOX-TYPED-OPTIONS-TEST-CASES.md`、
> `PROPERTY-CONDITIONAL-TEST-CASES.md`、`PROPERTY-ARRAY-TEST-CASES.md` 覆盖，不在此重跑。

## 前置

- 安装 `v1-suite.tlx`（已装好）。打开夹具 `tests/fixtures/addable-group-menu.tlp`：一条轨、一个 part，
  声库为 **`[v1-suite] Conditional`**，三个音符（第 2 个已填 `letters = ka`，故它的 `phonemes` 列表预先有 k / a 两行）。
- 选中音符看右侧 **Note 属性面板**；点 part 空白处看 **Part 属性面板**。
- 搜索阈值：菜单里可选叶子 **≥ 10** 才出搜索框。

## A · 下拉框：分组 + 搜索（Note 面板 `key`）

选中第 1 个音符。`key` 共 15 个叶子：Major ▸ 7 个；Minor ▸ Natural ▸ 4 个、Harmonic ▸ 4 个。

- [ ] 初始显示 **C major**（默认值落在分组里的叶子上也能正确显示）。
- [ ] 点开：顶部有搜索框且**已自动聚焦**（直接打字即可）；下面是 Major / Minor 两个带 ▸ 的分组行。
- [ ] 悬停 Minor → 弹出二级菜单 Natural / Harmonic；悬停 Natural → 弹出三级菜单，选 **D minor** → 下拉显示 D minor，菜单全部收起。
- [ ] 再开，输入 `harm` → 列表变成 4 行平铺结果，每行前缀灰字路径 `Minor › Harmonic  ›`，第一行高亮。
- [ ] 输入 `minor e`（两个词）→ 只剩 `E minor` 与 `E harmonic minor`（每个词都须命中「路径 + 项名」）。
- [ ] ↓/↑ 移动高亮（首尾循环），**Enter** 选中高亮项 → 值写入、菜单关闭。
- [ ] 输入 `zzz` → 显示灰字「无匹配项」；Enter 无反应。
- [ ] 清空搜索框 → 恢复分组树。
- [ ] 打开后按 **Esc** → 菜单关闭、值不变。点菜单外 → 关闭；再点一下下拉本体 → 是关着的就打开（不出现"点一次关、立刻又开"的闪烁）。
- [ ] 小下拉无搜索框：`mode`（2 项）、`pick` 点开**没有**搜索框，行为与之前一致。
- [ ] 多选三个音符 → `key` 显示 `(Multiple)`；选一项 → 三个音符都写入（撤销一次全部还原）。

## B · 列表 `+`：分组 + 搜索（Note 面板 `phonemes`）

候选：Phoneme、Rest、Vowels ▸ a e i o u、Consonants ▸ Plosive ▸ k t p、Nasal ▸ n m（共 12 个叶子）。

- [ ] 选第 2 个音符（已有 k / a 两行）。点 `phonemes` 底部 **+** → 弹出与下拉**同款**菜单（同样的底色、圆角、hover），顶部有搜索框。
- [ ] 悬停 Consonants ▸ Nasal ▸ 选 **n** → 列表末尾新增一行，内容为 `n`；原有 k / a 不变。
- [ ] 再点 +，输入 `plos` → 平铺出 k / t / p（前缀 `Consonants › Plosive`）；Enter → 新增 `k`。
- [ ] 选 **Rest**（顶层叶子）→ 新增 `-`。
- [ ] 选第 1 个音符（`letters` 为空 → 列表为空的 seed 态）→ + 加任意一项 → 出现一行，不报错。
- [ ] 每次添加都可撤销（Ctrl+Z 一次撤一行）。

## C · 键控容器 `+`：分组 + 隐藏已加键（Part 面板 `Mixed Speakers`）

候选：Female ▸ Alice、Carol；Male ▸ Bob（3 个叶子 → **无**搜索框）。

- [ ] 点 + → 两个分组 Female / Male，**无**搜索框。
- [ ] Male ▸ Bob → 出现 Bob 行。再点 + → **Male 分组整个消失**（组内已无可加的键），只剩 Female。
- [ ] Female ▸ Alice → 再点 + → 只剩一个候选 Carol：**直接加入 Carol、不弹菜单**（单叶子直加，分组里的也算）。
- [ ] 全部加完 → **+ 按钮隐藏**。删掉 Bob 行 → + 重新出现，菜单里只有 Male ▸ Bob。

## D · 回归：单候选 `+` 不弹菜单

- [ ] 设置窗 → 扩展页 → **V1 Engine Settings Demo** → `Servers` 列表点 + → **直接追加一行**、不弹菜单（只有一个候选，与之前一致）。
- [ ] 设置窗里**语言**下拉（16 种语言 ≥ 阈值）→ 点开有搜索框，输入 `日本` 或 `ja` 能定位并切换。

## E · 命令面：分组下拉可见、可写（已用 CLI 自测通过，可选复核）

- [ ] 让 agent「列出 [v1-suite] Conditional 的 note 参数」→ `key` 列出全部 15 个选项（之前是 `one of []`）。
- [ ] 让 agent「把第 1 个音符的 key 设成 E harmonic minor」→ 成功，面板显示 E harmonic minor。

## F · 元素行：序号条 / 浮出删除钮 / 间距

- [ ] 第 2 个音符的 `phonemes`：每个元素左侧有序号条（与音素标签同色 #626FFC、白字，与轨道头序号块同宽、无圆角），**贴满元素上下沿**、数字居中；元素之间、**首个元素头顶**、末个元素下沿各有一条 1px 实线（与字段间分隔线同色），整组上下封口。删掉第 1 个后，新的第 1 个头顶出现顶线、序号重排连续。
- [ ] 间距规则：容器字段标题（`phonemes` / `pair` / `Mixed Speakers`）下方留 12px（= 普通字段标题到控件的距离）；键控条目上下各留 10px；条目下方有控件时名字与控件之间再留 12px，空对象条目则不留。
- [ ] 悬停某个元素：元素右沿外 4px 处浮出 28×28 灰底白叉（与文本框、按钮同高），可越出面板右缘乃至窗口；**不占控件宽度、不遮控件**，元素本身无底色变化。指到叉上变红底；从元素移到叉上途中叉不消失；移开约 0.15 秒后收起。
- [ ] **不闪烁**：`Mixed Speakers` 条目（叉与条目有重叠）与 `phonemes` 元素，指针停在叉上数秒，叉保持红底常亮、不闪；在行与叉之间快速来回移动也不闪。
- [ ] 点叉删除后叉随即收起，不残留浮在原处。悬停时滚动面板，指针移出元素后叉收起。
- [ ] `pair`（定长数组）：有序号条与上下封口线，悬停**不出**叉；下方与分隔线之间有正常留白。
- [ ] 设置窗 → 扩展 → V1 Engine Settings Demo → `Servers`：复合元素（地址 + Ping）的序号条撑满整个元素高度，叉浮在元素右侧外、竖向居中，一眼看出删的是整个服务器。
- [ ] Part 面板 `Mixed Speakers`：条目之间有 1px 分隔线（首条头顶也有一条，左右与数组元素的线对齐）；条目顺序**恒为 Alice / Bob / Carol**（按插件候选目录）——删掉 Bob 再加回来，Bob 仍在第二位而不是跑到末尾或别处；条目无序号条、不可拖动；悬停条目时叉浮在条目右侧外；只有名字的空对象条目，名字到上下两条分隔线的距离**相等**（各 10px，名字下方不再多出一截）；三人全加完、+ 隐藏后，末条下方有正常留白。
- [ ] **右键序号条直接删除**（熟手快捷）：`phonemes` 先用 + 加到 5 个元素，指针停在第 1 个序号条上连续右键 → 每次删掉当前第 1 个、下一个上移补位，不弹菜单、不弹确认；Ctrl+Z 逐个恢复。
- [ ] 右键序号条**不**弹出任何右键菜单；`pair`（定长数组）右键序号条无反应；左键点序号条无反应。

## G · 拖序号条重排（仿轨道头拖拽）

准备：第 2 个音符的 `phonemes` 用 + 加到 5 个元素，内容各不相同（如 k a n i -）。

- [ ] 悬停序号条：光标为普通箭头。左键单击序号条**不**触发任何动作。
- [ ] 按住第 1 个序号条向下拖：被拖元素跟手移动、浮在其余元素之上；越过下方元素的中线时，那个元素**带缓动**向上让位。拖不出列表首尾。
- [ ] 拖到底：把第 1 个一直拖到列表最底 → 最后一个元素也让位，松手后被拖元素成为第 5 个；同理把第 5 个拖到顶成为第 1 个。复合元素高矮不同时（`Servers`）同样能挤到首尾。
- [ ] 拖到第 4 个位置松手 → 顺序变为 a n i k -，序号 1–5 连续、顶线在新的第 1 个元素头上；**正在编辑的文本内容不丢**。
- [ ] **Ctrl+Z 一次**恢复原顺序；Ctrl+Y 一次再变回。
- [ ] 拖动后不松手、拖回原位松手 → 不产生撤销步（Ctrl+Z 撤的是上一步别的操作）。
- [ ] 拖动中悬停的删除叉不浮出；松手后悬停恢复正常。
- [ ] 拖动中按下右键 / 切到别的窗口（捕获丢失）→ 元素回弹原位、不提交。
- [ ] `pair`（定长数组）：按住序号条拖动无反应。
- [ ] 第 1 个音符（`phonemes` 为 seed 态、未物化）：先用 + 加两项后拖动 → 正常；seed 行不塌。
- [ ] 多选：选第 2、3 个音符——两者 `phonemes` 等长时可拖、两个音符同步重排；不等长时按住拖动无反应。
- [ ] 设置窗 → V1 Engine Settings Demo → `Servers`：加到 3 个服务器、填不同地址，拖动复合元素（地址 + Ping）重排正常，高矮不同的元素让位量正确。

## H · 元素选中 / 多选（仿轨道头）

准备：第 2 个音符的 `phonemes` 加到 5 个元素（如 k a n i -）。

- [ ] 单击序号条 2 → 元素 2 选中：整行底色提亮 + 右缘 3px 强调条（同轨道头选中态）；再单击序号条 4 → 只剩 4 选中。
- [ ] **再点一下取消**：只有 4 选中时再单击序号条 4 → 取消选中（无任何选中）；选中 2、4 时单击 4 → 收敛为只选 4（不取消）；只有 4 选中时按住序号条 4 拖动 → 照常拖动，松手后 4 仍选中。
- [ ] Ctrl+单击 2、4 → 2、4 同时选中；再 Ctrl+单击 4 → 4 取消选中。
- [ ] 单击 1，再 Shift+单击 3 → 1–3 连选。
- [ ] 选中 1、2 后**拖序号条 1** → 1、2 一起跟手移动，其余元素让位；拖到底松手 → 顺序变为 n i - k a，选中仍在挪过去的 k、a 上。**Ctrl+Z 一次**复原。
- [ ] 非连续多选拖动：选中 1、3 拖 1 往下一格 → 1、3 都往下挪一格、彼此间隔不变。
- [ ] 选中 2、4 后**右键序号条 2**（已选中）→ 2、4 一起删除；Ctrl+Z 一次两个都回来。
- [ ] 选中 2 后**右键序号条 4**（未选中）→ 只删 4，2 仍选中。
- [ ] **Delete 键**：选中 2、3 后（焦点在序号条上）按 Delete → 2、3 删除，Ctrl+Z 一次复原。
- [ ] **文本框里的 Delete 是文本框逻辑**：选中 2、3 后，点进元素 1 的文本框，光标放在字符前按 Delete → 只删一个字符，2、3 **不**被删。
- [ ] 无选中时按 Delete（焦点在列表）→ 什么都不删。
- [ ] 悬浮叉只删它所在的那个元素：选中 2、3，点元素 4 的叉 → 只删 4。
- [ ] 换选另一个音符再回来 → 选区已清空。
- [ ] `pair`（定长数组）：单击序号条不出选中态。

## I · 分隔线（下拉 / + 菜单同形：`ComboBoxItem` / `AddableElement` / `AddableKey`.Separator）

- [ ] 下拉 `key`：展开 Minor → Natural 与 Harmonic 之间有一条分隔线（**分组内**分隔线）；分隔线不可点、不计入搜索结果。
- [ ] `phonemes` 的 +：Rest 之后有一条带标签「Sets」的分隔线（顶层）；Consonants 子菜单里 Plosive 与 Nasal 之间有一条纯线（分组内）。
- [ ] `phonemes` 的 + 搜索 `a`：结果里只有可选项，没有分隔线行。
- [ ] Note 面板 `tags` 的 +（键控容器）：菜单为「Warm」段标题 + Red，「Cool」段标题 + Green、Blue。
- [ ] 加入 Red → 再开 + 菜单：「Warm」段标题**随之消失**，只剩「Cool」段（不留孤零零的段标题）。
- [ ] 再加入 Green、Blue → + 隐藏（全部加完）；删掉 Green → + 重现，菜单为「Cool」段 + Green（Warm 段仍隐藏，因 Red 仍在）。
