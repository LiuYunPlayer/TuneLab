# V1 测试声库

一个用于验证扩展详情页的**测试声源引擎**。这一段用来展示*斜体*、**粗体**、~~删除线~~ 和 `行内代码`，
以及自动链接：https://example.com

![立绘](portrait.webp)

## 快速开始

这个声源在使用前需要一点配置：

1. 打开 **设置 → 扩展**，选择一个声库。
2. 在任意轨道上新建一个*声源片段*。
3. 输入歌词——每个音符会生成对应音素。

## 参数

| 参数   | 含义         | 默认值 |
| ------ | ------------ | ------ |
| speed  | 播放速度     | 1.0    |
| pitch  | 全局音高偏移 | 0      |
| breath | 气声量       | 0.3    |

## 画布字段

下面这些 note 字段由扩展自己绘制，值都是普通 JSON：

- **Stretch Curve**（`stretch`，核音素上也有同名的 `stretch`）：恰好 5 个数的数组，每个取 0..1，依次对应从 note 开头到结尾等距的点。默认 `[0, 0.25, 0.5, 0.75, 1]` 为线性。缺项或越界的点按线性处理。
- **Canvas Images**（`image_demo`）：一个数，星形的旋转角度（单位度，任意值；0 = 正立）。
