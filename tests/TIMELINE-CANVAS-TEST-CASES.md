# 参数面板画布测试用例

覆盖插件画布进参数面板（设计见 `docs/canvas-in-parameter-panel.md`）：时间轴画布（`TimelineCanvasConfig`）常驻参数面板、
侧栏画布钉进参数面板、画布露出范围（`VisibleBounds`）。按实现分期补充用例。

只测本功能。**不复测**侧栏画布本身的绘制、事件、草稿 / 提交、弹出（画布既有测试覆盖），参数面板多开、属性 lane 的数值行为。

## 前置

- 构建启动 TuneLab，安装测试插件 V1 Test Voice。打开测试工程：一个 part，声源 V1 Test Voice 的 Alice，4 个音符。

## A. 露出范围（VisibleBounds）

### A1. 侧栏滚动时标出露出的范围

选中一个音符，侧栏音符面板里找到「Canvas Images」画布，左上角有一行 `visible y 上–下 / 总高`。
把侧栏滚到这块画布只露出下半截、再只露出上半截。**期望**：数字跟着变——露出下半截时「上」大于 0，露出上半截时「下」小于总高，
文字始终贴在露出部分的顶上；整块露出时是 `0–总高`。滚动画布以外的内容（画布整块都在视野里）时数字不变。

### A2. 不影响别的画布

在侧栏里操作「拉伸曲线」画布（拖点、双击复位、滚轮微调）。**期望**：与以前一致。

## B. 标签栏（时间轴画布常驻、侧栏画布钉选）

测试插件 V1 Test Voice 声明了两个时间轴画布：音符级「Timeline Demo」、核音素级「Phoneme Timeline」。
参数面板里的画布本身后续才画出来，这一组只看标签、颜色与钉选。

### B1. 时间轴画布自动出现

打开工程、等合成完成。**期望**：底部标签栏（声源那一组末尾）出现「Timeline Demo」与「Phoneme Timeline」两个按钮，不用钉；
各有自己的颜色（不是灰色，也不与旁边的参数撞色）。侧栏音符面板、音素面板里**没有**这两个字段。

### B1b. 出现过就一直在

标签出现后，框选全部音符改一下音高（让全部音符标脏、等待重新合成）。**期望**：两个按钮一直在、位置与颜色不变，
合成期间不消失再出现。换一个声源（如换成 Bob 以外的别的引擎）再换回来，标签重新随合成出现。

### B2. 页签右键只开关可见

右键任一参数页签（含时间轴画布、钉上来的属性）。**期望**：只切换小眼睛（可见 / 不可见），不弹菜单。

### B3. 侧栏画布能钉

选中一个音符，右键侧栏里「Stretch Curve」画布的标题行。**期望**：菜单里有「在参数栏编辑」；点了之后标签栏多一个「Stretch Curve」按钮。
右键标签栏**空白处**直接弹出勾选列表：能钉的属性都在（音素级的带「（音素）」），已钉的打勾；点没勾的 = 钉上（标签栏多一个按钮），点打勾的 = 移除（按钮消失）。时间轴画布不在列表里。核音素面板里「Stretch」画布同理（钉成音素级）。

### B4. 画布参数不误写数值

点亮「Timeline Demo」或钉上的「Stretch Curve」，在参数面板里拖动、右键横扫。**期望**：什么都不发生（不写入任何值、没有撤销步骤），
面板左侧不显示上下界数值。

### B5. 布局保存

让一个面板激活「Timeline Demo」，保存成 `.tlpx`，关闭再打开。**期望**：那个面板仍激活「Timeline Demo」。

## C. 参数面板里的画布

### C1. 时间轴画布画出来

点亮「Timeline Demo」。**期望**：每个音符的时间段上一块画布：细边框，左上角 `note 起–止s`（这块覆盖的秒数，与音符的起止对得上；
相邻音符的块之间不留缝，块的左右边正好对齐音符的起止）。没有深色圆角底（透明，与自动化参数一致）。

### C2. 跟着时间轴

缩放、横向滚动钢琴窗。**期望**：画布块跟着音符走、宽度随缩放变；秒数不变。改变面板高度：画布高度跟着变。

### C3. 音素级

点亮「Phoneme Timeline」。**期望**：等合成完成后，每个核音素一块，`core 起–止s` 与音素块对得上。

### C4. 背景显示

让「Timeline Demo」可见（小眼睛开着）但激活别的参数（如 Volume）。**期望**：画布仍画着，但被半透明黑底压暗、在激活参数下面；
点在画布上不会触发画布（操作的是激活参数）。
再激活一个画布参数（如钉上的「Stretch Curve」）。**期望**：「Timeline Demo」这时不画（两层画布叠起来看不清），它的小眼睛也不点亮；背景里的曲线照常画。
切回 Volume，「Timeline Demo」又作为背景出现。

### C4b. 画布的小眼睛互斥

激活 Volume，打开「Timeline Demo」的小眼睛，再打开钉上的「Stretch Curve」的小眼睛。**期望**：「Timeline Demo」的小眼睛自动关掉，
背景里只画「Stretch Curve」。曲线参数（如 Growl）的小眼睛不受影响。激活「Stretch Curve」再切回 Volume：作背景的是「Stretch Curve」。

### C5. 钉进来的侧栏画布

钉上「Stretch Curve」并点亮。**期望**：每个音符一块拉伸曲线画布，能拖点编辑；改完撤销一次能撤回；侧栏里同一音符的「Stretch Curve」跟着变。

### C6. 滚轮

指针在画布上滚轮（插件不处理的地方）。**期望**：照常滚动 / 缩放时间轴。
