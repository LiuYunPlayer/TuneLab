# 参数面板画布测试用例

覆盖插件画布进参数面板（设计见 `docs/canvas-in-parameter-panel.md`）：时间轴画布（`TimelineCanvasConfig`）常驻参数面板、
侧栏画布钉进参数面板、画布露出范围（`VisibleBounds`）。按实现分期补充用例。

只测本功能。**不复测**侧栏画布本身的绘制、事件、草稿 / 提交、弹出（画布既有测试覆盖），参数面板多开、属性 lane 的数值行为。

## 前置

- 构建启动 TuneLab，安装测试插件 V1 Test Voice。打开测试工程：一个 part，声源 V1 Test Voice 的 Alice，4 个音符。

## A. 露出范围（VisibleBounds）

### A1. 侧栏滚动时标出露出的范围

选中一个音符，侧栏音符面板里找到「Canvas Images」画布，左上角有一行 `visible y 上–下 / 总高`。
把侧栏滚到这块画布只露出下半截、再只露出上半截。**期望**：数字跟着变——露出下半截时「上」大于 0，露出上半截时「下」小于总高，
文字始终贴在露出部分的顶上；整块露出时是 `0–总高`。滚动画布以外的内容（画布整块都在视野里）时数字不变。

### A2. 不影响别的画布

在侧栏里操作「拉伸曲线」画布（拖点、双击复位、滚轮微调）。**期望**：与以前一致。
