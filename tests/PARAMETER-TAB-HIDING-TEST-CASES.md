# 标签栏只留常用参数 —— 测试用例

标签栏空白处右键的勾选列表管「标签栏上显示哪些参数」。两类存储：原本常驻的（声源 / 效果器的自动化轨、时间轴画布）记被隐藏的，
原本不显示的（可钉属性）记被钉选的。只测这一块受影响的范围；时间轴画布本身见 TIMELINE-CANVAS-TEST-CASES.md。

## 前置

用测试声源「V1 Test Voice」的测试工程，part 上再挂一个效果器（有自己的自动化轨的那种）。

## A. 勾选列表

### A1. 列表内容与分组

在标签栏空白处右键。**期望**：一张勾选列表，按参数属于谁分组，每组前一条写着组名的分隔线，自上而下：声源名（它的自动化轨）/
音符（时间轴画布在前，可钉属性随后）/ 音素（同上）/ 各效果器名（各自的自动化轨）。标签栏的分组与顺序与之一致：声源、音符、音素、各效果器，组间各一条竖分隔线。自动化轨与时间轴画布默认都打勾，可钉属性只有钉了的打勾。点在页签按钮上右键不弹这张表（那是开关小眼睛）。

### A2. 连续勾选

在列表里接连点几项。**期望**：菜单不关，每点一下勾选态随即翻转，标签栏上对应的页签同时消失 / 出现。

### A3. 有数据的标记

先在某条自动化轨（如 Volume）上画几笔，再打开列表。**期望**：这一项后面标「(有数据)」；没画过的不标。
时间轴画布在某个音符上加过点之后也标「(有数据)」。

## B. 隐藏的效果

### B1. 页签消失、分组不留空

把某个效果器的自动化轨全部取消勾选。**期望**：这些页签消失，它们那一组前面的分隔线也不留。

### B2. 激活的那条被隐藏

激活 Volume 之外的某条轨，然后在列表里取消勾选它。**期望**：面板退回到 Volume；把 Volume 也藏起来，面板退回到标签栏上剩下的第一条。
重新勾上原来那条，面板自动回到它（激活记录没丢）。

### B3. 不作背景

把一条轨的小眼睛打开（作背景显示），再把它从标签栏隐藏。**期望**：面板里不再画它；重新显示后小眼睛还是开着的，又作背景画出来。

### B4. 隐藏不影响合成

在 Volume 上画一段明显的起伏后把它隐藏，播放或导出。**期望**：声音里仍有那段起伏。

### B5. 多块面板共用

开两块参数面板，在标签栏隐藏一条轨。**期望**：两块面板都不再显示它（激活着它的那块退回到别的参数）。

## C. 记住与入口

### C1. 跨工程、按声源记

隐藏几条后关闭再打开 TuneLab，或新建一个工程用同一个声源。**期望**：仍然隐藏着。换成别的声源：它们的参数不受影响。
效果器的轨按效果器类型记：在另一个 part 上挂同类型效果器，它的那几条也是隐藏的。

### C2. 侧栏编辑按钮把隐藏的画布放出来

把一条时间轴画布隐藏，再点侧栏里它那一行的编辑按钮。**期望**：它重新出现在标签栏上并被激活；列表里它又打上了勾。

### C3. 钉选照旧

在列表里勾上一个可钉属性，**期望**：同侧栏属性右键「在参数栏编辑」，页签出现；取消勾选即解钉，页签消失。

### C4. 命令面

用 CLI 跑 parameter.hideFromTabBar 与 parameter.showInTabBar（值写法 source:id、effect0:id、note:路径）。**期望**：效果同界面上勾选；
列出的值域每项带 shown / hidden；对已是目标态的再跑一次什么都不变。

## D. 标签栏右侧的入口按钮

### D1. 按钮与弹出位置

**期望**：标签栏最右（与左侧波形开关、「+」对称的那块空位）有一个勾选列表图标的按钮，悬停提示「标签栏显示的参数」。
点它弹出与空白处右键同一张勾选列表，贴着按钮向上展开、不出窗口；点选不关菜单。空白处右键照旧可用。

### D2. 默认隐藏的参数

测试声源有一条「Legacy Curve」声明为默认不显示。**期望**：标签栏上没有它，列表里它没打勾；勾上后出现、重启后仍在；
再取消勾选即消失。
