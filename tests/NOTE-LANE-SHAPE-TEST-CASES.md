# 属性 lane 按 note 声明测试用例

覆盖参数面板里钉选的 note 属性 lane 改为「每个 note 按自己的声明画、写」：字段只有部分 note 声明时 lane 照样出现、
只在这些 note 上有段；各 note 的量程按各自的声明；上下界标签随视口里的段而定；侧栏单选复用同一份声明。

只测本改动。**不复测** lane 本身的绘制手势（拖写、Ctrl 定值、右键清除的基本行为）、钉选存储与轨色、音素 lane 的几何。

## 前置

- 构建启动 TuneLab，打开测试工程：一个 part，声源是 V1 Test Suite 的「Conditional」音源（id suite-conditional），6 个音符，
  音高 C4 到 F4 依次升高；第 2、3、5 个音符的 mode 是 Advanced，其余是 Simple。
- 这个声源只给 mode = Advanced 的音符声明 gain（-12 到 12 的滑条）。

## A. 字段只有部分 note 声明

### A1. 能钉出 lane

单选第 2 个音符，在侧栏 gain 上右键 →「在参数栏编辑」。**期望**：参数栏标签栏多出 gain；点开它，
只有第 2、3、5 个音符上有段，第 1、4、6 个音符上是空的。（修复前：标签栏不出现 gain。）

### A2. 只写有段的 note

在 gain lane 上从第 1 个音符一路拖到第 6 个音符。**期望**：只有第 2、3、5 个音符的 gain 被写入（选中查看侧栏），
第 1、4、6 个音符侧栏里仍没有 gain 字段。右键横扫清除同理：只清第 2、3、5 个。

### A3. 改值后段跟着出现 / 消失

把第 4 个音符的 mode 改成 Advanced。**期望**：gain lane 上第 4 个音符立刻出现段（画在默认值 0 的高度）。
再改回 Simple，段消失。

## B. 上下界标签

### B1. 同轴时照常标

gain lane 激活时，**期望**：面板左上 / 左下照常显示 +12.00 / -12.00。

### B2. 视口里没有段

把视口滚到所有音符之外再看 gain lane。**期望**：仍显示 +12.00 / -12.00（退回标签栏那一份）。

## C. 侧栏

### C1. 单选与多选

依次单选各音符、再框选几个混合 mode 的音符。**期望**：侧栏字段与修复前一致（Advanced 的单选有 gain；多选按插件合并显示）；
改值、撤销后侧栏刷新正常。
