# 叠到钢琴窗上（PianoOverlay）—— 测试用例

画布（时间轴 lane 画布、时间轴画布）可以叠到钢琴窗的音符区上，和当前工具一起操作；音符区右上角的悬浮页签管理叠了哪些、顺序、激活与可见。
只测这一块受影响的范围；画布在参数区的叠放见 TIMELINE-CANVAS-TEST-CASES.md，标签栏隐藏见 PARAMETER-TAB-HIDING-TEST-CASES.md。
设计见 docs/canvas-stacking.md §3。

## 前置

用测试声源「V1 Test Voice」的测试工程（有时间轴 lane 画布 Timeline Demo / Markers、时间轴画布 Timeline Demo / Language、音素级 Phoneme Timeline），
part 上有若干音符（含相邻、和弦更好）。删掉 `%APPDATA%\TuneLab\Configs\PianoOverlay.json` 从空状态开始。

## A. 悬浮页签与「+」

### A1. 出现条件

打开 V1 Test Voice 的 part。**期望**：音符区右上角、时间轴下方出现一条带描边的悬浮条，只有「>」与「+」。换成没有任何画布的声源的 part：整条不出现。

### A2. 勾选列表

点「+」。**期望**：贴着「+」弹出勾选列表，首行是不可点的标题「Place on the Piano Roll」，其下按声源 / 音符 / 音素 / 各效果器分组，
组名分隔线同参数区标签栏的勾选列表；侧栏画布（如 Stretch Curve）与只传值的参数不在列表里。接连勾几项：菜单不关、勾选态随点随变，
悬浮条上页签同时出现 / 消失。

### A3. 再点「+」收起

列表开着时点「+」。**期望**：列表收起，不会立刻又弹出来。再点一次才重新弹出。

### A4. 新叠上的在最左

依次勾上 A、B。**期望**：B 在 A 的左边；音符区上 B 画在 A 之上。

## B. 顺序、激活、可见

### B1. 拖动排序

把最右的页签拖到最左。**期望**：被拖的跟手、不出首尾；越过邻居中线时邻居平滑让位；松手后顺序固定下来，叠放随之改变（最左的在最上）。
拖动过程中、松手时都不激活这个页签。

### B2. 激活 = 临时置顶

单击右侧某个页签。**期望**：它变成激活样式，画到最上；页签位置不变。再单击它：撤掉激活，叠放回到它在顺序里的位置。

### B3. 激活与可见脱钩

右键关掉某页签的小眼睛，再单击激活它。**期望**：激活期间显示；激活别的或撤掉激活后它不再显示（小眼睛仍是关的）。

### B4. 切换不闪

在几个页签间来回单击。**期望**：只有颜色过渡，整排不闪。

### B5. 收起 / 展开

点「>」。**期望**：页签与「+」带动画向右缩进去，只剩「<」；点「<」带动画展开。重启 TuneLab 后保持上次的收起状态。

## C. 画在哪、事件给谁

### C1. 位置与层次

音符工具下叠上 Timeline Demo（时间轴 lane 画布）与 Language（时间轴画布）。**期望**：时间轴 lane 画布铺满音符区；Language 在每个音符正下方贴一个语言标签。
都画在音符与音高线之上（「音符」固定标签在最右），框选框、波形带、顶部合成状态条在它们之上。波形带打开时画布只到波形带上沿，关了到参数区上沿。

### C2. 两个视图各叠各的

音符工具下叠着 Language，切到画笔工具。**期望**：悬浮页签整排换成音高视图的：只有「音高」固定标签（和「+」），Language 不在，音符区上也不画它。
在画笔工具下叠上 Timeline Demo，切到锚点 / 固定笔刷 / 颤音：页签不变（同属音高视图）。切回音符工具：又是 Language +「音符」，没有 Timeline Demo。

### C3. 空白处交给工具

叠着 Language，在标签以外的地方：单击空白取消选中、框选、拖音符、用音高笔画音高。**期望**：都照常生效；中键拖动平移、松手后不粘在鼠标上。

### C4. 画布接住的归画布

点 Language 标签。**期望**：弹语言菜单，选完标签更新，可撤销；这一下不会同时选中 / 取消选中音符。

### C5. 选区右键宿主先截

Shift 拉一段范围选区，在选区带内、Language 标签上右键。**期望**：弹的是选区菜单，不是语言菜单。

### C6. 与参数区同步

参数区激活 Language lane（其标签多半在面板外看不到属正常），同时钢琴窗上叠着它；在钢琴窗上改一个音符的语言。
**期望**：侧栏该行摘要随之更新；撤销后钢琴窗上的标签恢复。

## D. 存储与动作

### D1. 跨工程

叠几块、排好顺序、关掉一个小眼睛，关闭再打开另一个用同一声源的工程。**期望**：叠放、顺序、可见、激活原样。

### D2. 声明消失后恢复

换成别的声源再换回来。**期望**：换走时页签消失，换回后原样恢复。

### D3. 动作面

`tunelab action list` 里有 `parameter.placeOnPianoRoll` / `removeFromPianoRoll`，值域是能叠的画布（每个值标 on / not on the piano roll）；
`action run parameter.placeOnPianoRoll` 给一个值。**期望**：效果同在「+」列表里打勾；已叠的再叠什么都不变。

## E. 参数区页签：再点一下回到上一个

### E1. 往回退

依次单击参数页签 A → B → C，再单击 C。**期望**：回到 B；再单击 B 回到 A；历史用完回到默认那条（Volume）。

### E2. 右键已激活的页签 = 退回背景并开着小眼睛

先右键关掉某页签的小眼睛，再单击激活它，然后右键它。**期望**：撤掉激活，小眼睛变成开着，画布留在原位继续显示。
参数区同理：激活 Gain 后右键它，回到上一个激活的参数，Gain 开着小眼睛作背景显示。参数区藏起来（Ctrl+P）时单击页签仍是显示参数区并激活它。

## F. 固定层：音符 / 音高

### F1. 默认位置

删掉 PianoOverlay.json 后：音符工具下「音符」标签在最右（最底），新叠上的画布出现在它左边；画笔工具下「音高」标签在最左（最上），
新叠上的画布出现在它右边（垫在音高线下）。

### F2. 音高视图：垫在音高线下

画笔工具下叠上 Timeline Demo（时间轴 lane 画布，铺满音符区）。**期望**：画布被遮罩压暗、只画格子（作背景），音高线在它上面；
在画布区域里照常能画音高，画布不接任何按下。

### F3. 拖到固定层之上

把 Timeline Demo 拖到「音高」左边。**期望**：它到遮罩与音高线之上、全亮、画文字（不再作背景），按下先问它；它不接的（空白处）照常画音高。
拖回「音高」右边即恢复 F2。

### F4. 音符视图同理

音符工具下把「音符」标签拖到 Language 左边。**期望**：Language 垫到音符下面、作背景、不接按下（点它的标签位置 = 点音符区空白）；
音高线仍附在音符正上方。拖回即恢复。

### F5. 固定标签只能拖

单击、右键「音符」/「音高」标签。**期望**：什么都不发生（不激活、没有小眼睛），悬停也没有提示。标签是不透明底（同标签条底色）加一圈描边，一眼和画布标签区分开。

### F6. 激活不受固定层限制

把某块画布放在固定层之下，单击它的标签激活。**期望**：它临时到最上、全亮、收事件；再点一下退回原位、作背景。

### F7. 动作面跟着当前视图

画笔工具下用动作 parameter.placeOnPianoRoll 叠 Markers。**期望**：叠进音高视图（紧贴音高线下）；切到音符工具看不到它。
