# Agent 导出工程（`export_project`）测试用例

覆盖 B 支柱最后一块**导出**：把当前工程写成一个文件，`project.importTracks(path)` 的对偶。

**归属**：工具面（不是 `tl` 脚本原语）——导出不改工程状态，与 `save_script`/`delete_script` 同类；且授权闸门是 async，
而脚本同步跑在 UI 线程、中途等卡片会自死锁。

**三条必须成立的语义**（本轮重点验的就是这三条）：
1. **恒过授权闸门**（不像 `save_script` 只拦覆盖）——路径任意 = 能写用户磁盘任何地方；
2. **导出 ≠ 保存**——不改工程保存路径、不清未保存态、不进最近文件列表；
3. **失败不落半截文件**——序列化在闸门之前，写文件是最后一步。

## 前置

- 打开 TuneLab，工程里有若干轨（含音符；最好有一轨挂了音源 + 有 effect + 有自动化曲线，供验保真）。
- **让工程处于"有未保存改动"状态**（随便改一下，标题栏应有未保存标记）——这是验语义 2 的关键前置。
- 备一个空文件夹作落点，记下绝对路径；另备一个**已存在的**文件供覆盖测试。
- Agent 侧栏已连模型。授权档位先置 **Confirm**（验卡片），后面再切 Auto / ReadOnlyAdvice 各过一遍。

## 1. 导出 .tlpx（全保真）+ 闸门卡片

跟 agent 说「把当前工程导出到 `<空文件夹>\a.tlpx`」。

**期望**：
- 弹**授权卡片**，且卡片上摆着**完整落地路径**（不是只有文件名）+ 格式显示名；
- 点「应用本次」→ 文件生成；回报含路径、格式、文件大小，并**明说这是副本**（工程保存路径与未保存改动不变）；
- **标题栏的未保存标记仍在**、`文件 > 最近打开` 里**没有** a.tlpx（语义 2）；
- 用 TuneLab 打开 a.tlpx：音符/音源/effect/自动化/音素全保真，**播放头落在导出那刻的位置**。

## 2. 导出 .mid → **应当如实报「不支持」**（内置 MIDI 是只读的）

导出到 `<空文件夹>\a.mid`。

**期望**：**报错**「`.mid` 没有任何已装格式提供导出」+ 列出真正支持的扩展名（默认环境 = `.tlp`/`.tlpx`）；
**不产生文件**、不弹授权卡片。

**这不是缺陷，是事实**：内置 MIDI 格式只实现了 `IImportFormat`（`Midi.cs` 里没有 `Serialize`），
`LoadBuiltIn()` 也只 `RegisterImporter`——**能导入、不能导出**。所以 `importTracks` 读得进 mid、`export_project` 写不出 mid，
这个不对称是宿主的真实现状。核对办法：菜单「导出为」里同样只有 tlp/tlpx（它就是从 `GetAllExportFormats()` 生成的）。

**若装了提供 foreign 导出的格式插件**，再验一次 foreign 路径：导出成功且 `SerializeNative` 内部自动降级到纯 musical
`Serialize`（不报"不支持 native"之类的错）。

## 3. 覆盖已存文件 → 另一档文案

对**已存在**的文件导出。

**期望**：卡片文案是 `ProjectExportOverwrite` 那档——除了路径，**另起一行**明说「该位置已有文件，会被替换、无法撤销」；
拒绝则文件**分毫未动**（原内容还在）；同意则被替换。

## 4. 闸门三档

- **Auto**：不弹卡片直接写；回报无"用户已确认"前缀。
- **Confirm** → 点「拒绝」：**文件未生成**（新建场景下目标路径应仍不存在），回报明说用户不允许。
- **ReadOnlyAdvice**：**不写**，回报说明"处于只读建议档、我没有导出"并给出提权或手动的建议。
- **Confirm** → 点「始终允许」：本次写入 + 授权切到 Auto（头部胶囊应同步变），下一次导出不再问。

## 5. 错误路径（都应在**弹卡片之前**就报错，且不产生任何文件）

- 不支持的扩展名（如 `a.xyz`）→ 报错并**列出支持的扩展名清单**；
- **无扩展名**（如 `a`）→ 报"没有扩展名、无从确定格式"+ 清单；
- 父目录不存在 → 报错并明说**本工具不会创建文件夹**；
- 传一个**目录**路径 → 报"这是文件夹不是文件路径"；
- 空 `path` → 报 `"path" is required.`；
- 非法路径字符 → 报"不是可用的文件路径"。

**关键**：以上每一条都**不应弹授权卡片**（不为注定失败的请求打扰用户），且落点目录里不应出现任何新文件、
也不应出现 0 字节的半截文件。

## 6. 闸门等待期路径被占（越权防护，可选但值得一试）

导出到一个**不存在**的路径 → 卡片弹出后**先别点**，去资源管理器在那个路径手动建一个同名文件（或用任意编辑器存一个）
→ 再回来点「应用本次」。

**期望**：**不覆盖**那个文件（用户只同意了"新建"、没同意"替换"），回报明说"等待授权期间该路径出现了文件、
只获准新建故什么都没写、要替换请再说一次"。手动建的那个文件内容**分毫未动**。

## 7. 音频导出被正确拒绝且**给出出路**

跟 agent 说「导出成 wav / 帮我导出音频」。

**期望**：agent **不**调 `export_project` 硬试（就算试了也应被 `.wav` 不在导出格式里而报错）；
它应当**告诉用户音频导出要自己在导出面板按**（可顺带帮忙把参数说清），并说明原因（渲染期间界面会被占住）。
**不应**出现「我已帮你导出音频」这类假话。

## 8. 「导出 ≠ 保存」的措辞（易犯的误导）

跟 agent 说「帮我保存工程」。

**期望**：agent **不**用 `export_project` 冒充保存后宣称"已保存"。它可以导出一份副本，但必须说清那是副本、
真正的保存要用户自己按 Ctrl+S（或说明它做不到保存）。**说"已帮你保存了工程"即为不通过。**

## 9. 回归：Editor 自身的保存/另存/自动保存

本切片把 `Project.GetExportConfig/SetExportConfig` 提成了 `IProjectExtension` 扩展方法（调用点未改）。
故需回归：**Ctrl+S 保存**、**另存为**、**导出为**、**自动保存**、**打开工程**（`SetExportConfig` 回灌）
——各走一遍，导出设置（导出面板里的路径/格式/采样率/位深/码率/主输出开关与声道）应在保存-重开后**保持原值**。
