# 参数面板多开测试用例

覆盖钢琴窗下方的参数面板多开（设计见 `docs/parameter-panels.md`）：面板堆的增删、焦点、收起、整区隐藏、
高度压缩、布局随工程保存，以及对应的动作面与 `editor status`。

只测本功能。**不复测**单个参数面板内部的编辑手势（画曲线、锚点、固定笔刷、回显轨烘焙等）、属性 lane 钉选、
快捷键系统本身。

## 前置

- 构建启动 TuneLab，打开一个工程：至少一个带**歌声声源**的 part（有插件参数），part 上挂**一个效果器**（标签栏 `|` 后面会多一组）。
- 下文「标题栏」指参数面板自己的标题栏（左侧三角 + 参数名，右侧回显 chip 与「×」）；「标签栏」指钢琴窗最底下那一条参数按钮。
- 命令面用例在 TuneLab 开着时用 `TuneLab.Cli.exe` 跑（attach，不加 `--headless`）。

## A. 增删

### A1. 「+」加面板

点标签栏最左侧的「+」。**期望**：焦点面板下方多一块，参数、可见集、回显显隐、高度都照着焦点面板；新的一块成为焦点（参数名右侧出现圆点）。

### A2. 「×」关面板

有两块以上时，点某块标题栏最右的「×」。**期望**：那一块消失；关的是焦点面板则焦点交给它上面那块（没有上面的就是新的第一块）。
只剩一块时**没有「×」**。

### A3. 右键「+」关焦点面板

两块以上时右键「+」。**期望**：关掉焦点面板，不会同时又加一块。只剩一块时右键「+」**什么都不发生**；左键「+」照常加。

### A4. 标题栏右键菜单

在标题栏空白处右键。**期望**：弹出菜单；一块时只有「隐藏参数面板」，两块以上还有「关闭面板」。

## B. 焦点

### B1. 按标题栏切焦点

在非焦点面板标题栏的空白处或参数名上点一下。**期望**：圆点移到这块，标签栏改为显示并修改这块的激活 / 可见参数。
拖动它的标题栏改高度**也**切焦点。

### B2. 以下都不切焦点

在非焦点面板里：画曲线、选点、拖锚点；点它的收起三角、「×」、回显 chip。**期望**：圆点不动。之后在标签栏切参数，改的仍是原焦点面板（「常驻几块 + 一块主面板」的用法）。

### B3. 焦点样式

**期望**：所有面板参数名都是白字（不用亮暗区分焦点）；只有焦点面板参数名右侧有参数色的小圆点；切焦点时右边的回显 chip 不跳动。

## C. 收起与整区隐藏

### C1. 单块收起

点标题栏左侧三角。**期望**：只剩标题栏，三角朝向变；再点展开回原高度。焦点不变。

### C2. Ctrl+P 整区隐藏

按 `Ctrl+P`。**期望**：整个参数区连标题栏都不见，钢琴窗铺到底，波形带贴到最底；标签栏所有参数按钮都**不点亮**（眼睛图标照旧）。

### C3. 唤醒

在 C2 状态下分别：再按 `Ctrl+P`；点任一参数按钮；左键点「+」。**期望**：
- `Ctrl+P`：原样恢复，原激活按钮重新点亮；
- 点参数按钮：参数区显示，焦点面板换成所点参数；
- 「+」：只显示参数区，**不**多加面板。

### C4. 右键「隐藏参数面板」

**期望**：同 `Ctrl+P` 的隐藏。

## D. 高度

### D1. 拖动只改一块

拖某块标题栏。**期望**：只这一块变高 / 变矮，其余面板高度不变，差额由钢琴窗吸收。

### D2. 放不下时按比例压缩

开三四块、把窗口缩矮。**期望**：展开的面板按比例一起变矮，每块至少保留约 60（刻度轴上下两端的数值标签不重叠）；窗口放大后各块长回原高。

## E. 波形开关

### E1. 位置与样式

**期望**：波形开关在标签栏最左、「+」左边，面板标题栏上没有波形开关。开着 = 高亮底色 + 白图标，关着 = 无底色 + 半透明图标；「+」图标纯白。

## F. 随工程保存

### F1. 保存与还原

摆出 3 块面板：各选不同参数（其中一块选效果器 `|` 后面的参数）、收起一块、改几块高度、让中间那块成为焦点。改一下音符后保存成 `.tlpx`，关闭再打开。
**期望**：面板数、各自激活 / 可见参数、点亮的回显、高度、收起、焦点都原样。

### F2. 只改布局不算已修改

只动面板（加、关、收起、换参数、换焦点、拖高度）。**期望**：标题栏不出现未保存星号；`Ctrl+Z` 不撤销这些。

### F3. 旧工程与新建

打开一个没有布局的工程（旧 `.tlpx`、`.tlp`），以及「文件 → 新建」。**期望**：都得到默认的单块面板，不带上一个工程的布局。

### F4. 效果器参数认回

F1 存好的工程里，把效果器链重排（若有两个效果器）后保存再开。**期望**：效果器参数那块仍指向同一个效果器（跟着实例走，不跟位置走）。

## G. 动作面与状态（命令行）

### G1. 动作列表

`TuneLab.Cli.exe action list`。**期望**：有 `view.showParameterPanel` / `hideParameterPanel` / `addParameterPanel` /
`closeParameterPanel` / `collapseParameterPanel` / `expandParameterPanel` / `focusParameterPanel`；后四条带 `panel` 参数，
值为自上而下 1-based 序号，标签是激活参数名，状态标 focused / collapsed；关、收起、展开的参数可选（不给 = 焦点面板），聚焦必填。

### G2. 逐条执行

依次 `action run --id view.addParameterPanel`、`--id view.collapseParameterPanel --argument 1`、`--id view.focusParameterPanel --argument 1`、
`--id view.closeParameterPanel`（直到剩一块）、`--id view.hideParameterPanel`、`--id view.showParameterPanel`。
**期望**：界面随之变化；每条回报里的 `Parameter panel:` 一行列出各块（如 `#1 "张力" [focused, collapsed]`）。
只剩一块时 `closeParameterPanel` 报「the last one cannot be closed」；`--argument 9` 报不在合法值里并列出合法值，界面不变。

### G3. editor status

`TuneLab.Cli.exe editor status --json`。**期望**：`parameterPanelVisible` 反映整区是否显示；`parameterPanels` 自上而下列出各块的
`number` / `parameter` / `focused` / `collapsed`。

### G4. 导出带布局

在界面里摆好多块面板后 `project export --path ...\x.tlpx`，再打开导出的文件。**期望**：布局与导出时一致。
`--headless` 下导出的文件不带布局（打开为单块面板）。
