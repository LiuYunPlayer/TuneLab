# 回显轨 ⇄ 可编辑轨配对 + 固定 测试用例

> 本文覆盖**本次改动的受影响范围**：某些引擎希望"回显参数能调"，落地形态 = **同 Id 配对**（SDK 零改动）。
>
> - **配对判据**：引擎在 `GetAutomationConfigs` 与 `GetSynthesizedParameterConfigs` 声明同一 `PropertyKey.Id`
>   ⇒ 宿主视为"模型建议 + 用户覆盖"同一参数。`DisplayText` **各自自由**（不要求同名），量程也**不作要求**。
> - **显隐单向联动**：点亮可编辑轨（灭→亮那一刻）⇒ 同 Id 回显轨一起亮；熄灭编辑轨**不**连带熄灭回显；回显 chip 仍可手动关。
> - **固定**（`SynthesisLock`，与音素钉死同一范式）：把产物按**真实数值**写成用户曲线的锚点，一次可撤销。
>   两个入口：范围选区右键菜单（选区 / 整轨）与**固定笔刷**（按 `4`，笔刷式局部固定）。
>   参数区作用于当前活动轨的配对回显；音符区作用于合成音高 → Pitch（同一份实现）。
>
> 连带修的三处问题：**固定笔刷**在参数区原本退化成普通画笔；**锚点工具**在分段轨上原本只能双击插孤立点；
> **固定没扣 vibrato 偏移**导致每刷一次颤音幅度翻一圈（既有 `LockPitch` 就有的致命 bug，随本次合流修掉）。
>
> 回显轨自身的声明 / 显隐 / 绘制基线见 `SYNTHESIZED-PARAMETER-READBACK-TEST-CASES.md`，不在此重复。
> 每个用例：**做什么 → 预期看到什么**。

## 准备

```bash
dotnet build TuneLab.sln -c Debug
dotnet build tests/plugins/V1.Voice/V1.Voice.csproj -t:Rebuild -c Debug
powershell -File tests/pack-tlx.ps1

```

涉及的 UI 显示名（v1-voice，声库 `Alice (V1 Test)` / `Bob (V1 Test)`）：

| 名称 | 位置 | 是什么 |
|---|---|---|
| **Energy** | 参数区标题栏 chip（粉 `#E573B0`） | 只读回显轨，Id = `energy`，0..100 |
| **Energy (Actual)** | 底部 tabbar（橙 `#E5B073`） | **与回显同 Id** 的可编辑分段轨（实参轨），0..100 |
| **Energy** | 底部 tabbar（紫 `#B073E5`） | 偏差轨，Id = `energy_offset`，连续、默认 0、-50..50（**不配对**） |
| **固定笔刷** | 工具栏第 4 个 / 快捷键 `4` | 原名「音高锁定笔刷」，现为「固定笔刷」（`Locking Brush`，去掉了 Pitch 限定） |

> 命名刻意分层：tabbar 里是「Energy」(偏差) 与「Energy (Actual)」(实参)，chip 里是「Energy」(回显) —— 三者不重名，
> 且回显名对齐用户认知的物理量。这正是"显示名不必一致"的用例。

引擎行为（参照实现）：每合成一块产一条 `energy` 回显曲线 = **实参轨非 NaN 段用用户值、NaN 段用模型自算正弦（10..90）**，
末尾叠加偏差轨。所以覆盖过的地方，回显会与实参轨**重合**——肉眼即可验证"用户覆盖真的回喂进了合成"。

## 一、配对识别与单向联动

### 1. 点亮实参轨 ⇒ 回显自动亮
- 新建用 `Alice (V1 Test)` 的 MIDI part，写几个 note。确认标题栏 **Energy** chip **未点亮**。
- 底部 tabbar 切到 **Energy (Actual)**（或点它的小眼睛）。
- 预期：chip 上的 **Energy** 自动点亮（眼睛变粉）。触发合成后参数区出现粉色积分面积（回显）+ 橙色实参轨。

### 2. 点亮不配对的轨不联动
- 先把 **Energy** chip 手动熄灭。切到 tabbar 的 **Energy**（紫、偏差轨）或 **Bend**。
- 预期：chip 的 Energy **不**点亮 —— 只有同 Id 才算配对。

### 3. 熄灭编辑轨不连带熄灭回显
- 点亮 **Energy (Actual)**（回显随之亮）→ 再熄灭 **Energy (Actual)** 的小眼睛。
- 预期：回显**仍亮**。理由：只看回显是独立的合法用法，联动只负责"带亮"。

### 4. 回显 chip 可手动关（不锁）
- 在 **Energy (Actual)** 亮着时单击 chip 的 **Energy** 熄灭它。
- 预期：能关掉、且不会被自动点回来（一次性带亮，不是持续绑定）。
- 再切到别的轨、切回 **Energy (Actual)**：因为它已可见，**不**重新带亮回显（灭→亮那一刻才联动）。

## 二、固定的语义（用固定笔刷验证）

> 入口只有两个：**固定笔刷**（按 `4`）与**颤音右键**。曾加过的范围选区右键菜单已删（与笔刷重复；
> 将来作用域更灵活的入口交给脚本面，由用户自己决定放在哪）。

### 5. 无配对回显时不动作
- 未合成过（引擎还没产出回显）时，用固定笔刷在 **Energy (Actual)** 上拖 → **什么都不发生**。
- 活动轨切到 **Bend**（无配对回显）→ 拖 → 同样什么都不发生（不画线、不产生 undo 项）。

### 6. 刷过的范围与回显吻合
- 触发合成、回显出现后，活动轨 = **Energy (Actual)**，用固定笔刷刷过一段。
- 预期：
  - 刷过范围内出现橙色实参轨曲线，形状与粉色回显面积的轮廓**吻合**；范围外仍空。
  - 曲线两端**恰好收在刷到的位置**（跨边界处按插值补点）。
  - 重合成后，覆盖段的回显与实参轨**重合**（回显 = 引擎实际用的值），未覆盖段仍是正弦。

### 7. 段间空隙不被填平
- 让回显有多段（写两簇隔开的 note），整段刷过去。
- 预期：回显有几段就写几段，段间空隙**保持为空**——分段轨的 NaN 区不被填平。

### 8. 撤销对称
- 刷完一笔后按 Ctrl+Z。
- 预期：实参轨**一次性**回到刷之前（不是一段段撤）。Ctrl+Y 重做恢复。
- 撤销/重做过程中不应出现"用户没做过的变更"（合成结果不进 undo 栈）。

### 9. 固定后可继续手改（本需求的核心动机）
- 固定进实参轨后，用锚点工具改中间一小段（拖锚点或重画）。
- 预期：只有改动那段变化，其余仍是模型输出的形状 —— 即"抓住模型这根线只改中间一段"成立。
- 重合成后回显跟着变成改后的形状（覆盖回喂）。

### 10. 偏差轨与实参轨互不干扰
- 在紫色 **Energy**（偏差轨）上画一段正偏移。
- 预期：回显整体抬高（叠加偏差），实参轨曲线本身不动；两个入口各自独立。

## 三、固定笔刷

### 11. 刷进实参轨
- 活动轨 = **Energy (Actual)**，已合成出粉色回显。按 `4` 切固定笔刷，在参数区从左往右拖一段。
- 预期：拖过的范围内实参轨曲线即时出现并与回显轮廓吻合；拖动中来回移动 → 范围只扩不缩（累积口径同音符区）。
- 松手后 Ctrl+Z：**一次**撤销整笔。

### 12. 无配对回显的轨上不动作
- 活动轨切到 **Bend** 或紫色 **Energy**（偏差轨），用固定笔刷拖。
- 预期：**什么都不发生**（不画线、不产生 undo 项）。固定笔刷只做"固定模型输出"，不退化成普通画笔。

### 13. 右键擦除
- 在实参轨上用固定笔刷**右键**拖。
- 预期：擦掉刷过范围的曲线（与音符区固定笔的右键擦除对称）。

### 14. 工具名
- 看工具栏第 4 个按钮的 tooltip 与 快捷键设置窗里的命令名。
- 预期：中文「固定笔刷」、英文 `Locking Brush`（**不再带 Pitch**）。快捷键仍是 `4`，自定义键位（id `tool.lock`）不受影响。

### 14b. 拖动期引擎不被反复标脏（本轮机制改动，重点）
- 活动轨 = **Energy (Actual)**，已有回显。用固定笔刷**慢慢横拖一大段**（3 秒以上、来回移动），观察拖动期间：
- 预期：
  - 曲线**连续跟随**刷过的范围增长，**不会刷到一半就没了**（此前第一帧写入即触发失效、引擎清掉回显，后续帧读不到数据、整笔白刷）。
  - 拖动期状态带（合成进度条）**不逐帧闪**——失效被推到松手才发一次。松手后才看到该区间转为待合成。
- 同样拖一段 **Bend**（普通分段轨）或画 pitch：拖动期状态带同样不再逐帧闪，松手才标脏。这是所有拖动式编辑的通用改善。

### 14c. 范围选区右键菜单已删（回归确认）
- 造一个范围选区，在**参数区**和**音符区**分别 Shift+右键。
- 预期：菜单里**没有**「固定模型输出」/「固定合成音高」；复制/剪切/删除/粘贴族与脚本工具项照旧。

## 四、颤音幂等（致命 bug 回归，优先测）

> 产物已含 vibrato 偏移（引擎收的是「曲线 + 偏差」两条，最终音高 = 曲线 + 偏差）。原样写回用户曲线会让
> 重合成再叠一次偏差 ⇒ **每固定一次颤音幅度翻一圈**。现在写入前扣掉该轨的偏移，使固定**幂等**。

### 15. 音高固定不放大颤音（需真引擎，v1-voice 的 SynthesizedPitch 恒空）
- 用一个真的会产合成音高的声源，画一个颤音（Vibrato 工具），让它合成。
- 用固定笔刷在音符区刷过颤音覆盖区，重合成。
- 预期：**颤音幅度不变**（与刷之前听/看起来一致）。
- 在同一位置**反复刷 3～5 次**、每次都重合成。
- 预期：幅度**始终不变**（幂等），不会一圈圈变大。曲线本身应是"去掉颤音后的平滑基线"，颤音由 vibrato 叠加回来。

### 16. 参数轨的连续轨同理（当前无夹具覆盖，记 N/A 或用真引擎）
- 若某引擎声明了**连续型**实参轨（与回显同 Id）且该轨被某颤音关联（`AffectedAutomations`）：
- 预期：固定该轨后重合成，曲线值不被颤音二次放大；反复固定结果稳定。
- v1-voice 的实参轨是分段轨（分段轨不参与 vibrato），故此项夹具不覆盖。

### 16b. 编辑颤音即自动补基线（本轮新增，重点）
> 碰颤音的任何属性，都会先把它**已关联的分段轨**在覆盖区内的**空隙**固定成模型输出——否则颤音在那儿
> 没东西可叠、拖了没反应。硬边界：**只填空隙、绝不覆盖已画的值**。

- 活动轨 = **Energy (Actual)**，先合成出回显；轨上**什么都不画**（整条空）。
- 在参数区拖该区间的颤音块关联并调振幅。
  - 预期：落笔那一刻覆盖区内**出现橙色曲线**（模型输出被固定进来），随即颤音波动可见、拖振幅立刻有反应。
- 撤销一次 → **同时**回到「无曲线 + 未关联」（一次按下抬起 = 一个撤销单元，不该撤两次）。
- **不覆盖已画值**：先在颤音区左半段手画一条明显不同的曲线（压到很低），再拖该颤音的振幅。
  - 预期：左半段**保持你画的形状**，只有右半的空隙被填上。
- **区间变化按新区间补**：把颤音**拖到**空白区、或从右端**拉长**进空白区。
  - 预期：拖动**过程中**新覆盖区就持续被补上基线（不是松手才补），颤音效果实时可见；旧位置已固定的曲线**保留不删**（那已是用户数据）。
- **其他属性同样触发**：改频率 / 相位 / attack / release —— 覆盖区仍有空隙则补上，已满则无变化。
- 音符区拖颤音的 pitch 幅度：pitch 自身不需要基线（双通道），但同样会给已关联的参数轨补空隙。
- 反面：颤音**未关联**该轨（振幅 0）时编辑它 → **不该**产生任何曲线。

### 16c. 扩大颤音区间时接缝不冒尖峰（回归）
- 先让一段实参轨被固定（比如按 16b 关联颤音后自动补上，或用固定笔刷刷一段），颤音区间 = 该段。
- 把颤音的**左边界往左拖**扩大区间（右边界同理）。
- 预期：新扩出来的区间被补上基线，**与原有段的接缝处平滑相接**——不出现极窄的向上/向下尖峰。
- 原因（供定位用）：空隙的边界点坐标恰好等于原有段的端点，若按「原本有值就扣 vibrato」逐点判，这个点会被
  误判成有值而扣掉一个非零偏差（左边界拉长后它已落进颤音区内部），接缝处就是一根针。空隙填充整段都不扣偏差。

## 五、锚点工具（分段轨连线预览）

> 分段轨此前只能"双击插孤立点"，连不成线。本次把 pitch 锚点工具的**连线预览 + 单击接上**机制补到参数区分段轨。

### 17. 预览与单击连线
- 活动轨 = **Energy (Actual)**，按 `3` 切锚点工具。先双击一处产生一个点（它自动处于选中态）。
- 把鼠标移到该点右侧空白处（不要点击）。
- 预期：出现一条**白色预览线**，从选中点连到鼠标位置。
- 单击 → 预览变成真曲线（新点并入该段），可继续右移再单击、连续成线。

### 18. 悬浮段首/段尾连接两段
- 造出两段独立曲线（中间用右键擦开）。
- **先点选左段的最后一个锚点**（出现选中环）——连接的前提是「相邻组里有选中锚点」。
- 把鼠标悬浮到**右段的第一个**锚点上（先别点）。
- 预期：出现白色预览线，把两段接成一段。
- **单击 → 真的接上**（点了不动也必须生效）。
- **按一次 Ctrl+Z 就回到两段**——一次按下抬起是一个撤销单元，不该要撤两次。
- 反向同样成立：先点选右段首锚点 → 悬浮左段末锚点 → 单击接上。
- 悬浮到某段**中间**的锚点上：**无**预览（那是纯拖拽目标）。
- 回归项：**纯点击一个锚点**（不拖动、不连接）不该产生撤销单元——点几下再 Ctrl+Z，撤掉的应是那之前的编辑。
- pitch 侧同样修了：在音符区用锚点工具做同样的「点端点连两段」，行为与参数区一致。

### 19. 预览不残留
- 有预览时切到别的工具、或切到别的轨、或把鼠标移出参数区。
- 预期：预览线消失；切回来后单击不会"莫名插点"（预览项每轮重建，不跨轮残留）。

## 六、音符区固定（合成音高 → Pitch）

### 20. 菜单与笔刷两个入口
- 有合成音高时：Shift+右键音符区 → `固定合成音高`（`Lock Synthesized Pitch`）→ 选区内 / 整条轨；
  以及固定笔刷直接刷（同一份实现）。
- 预期：合成音高被写成用户 Pitch 曲线（此后与手画的 pitch 无区别，可继续编辑、可撤销）。
- 无合成音高时：该菜单项**不出现**。
- **注意合流带来的两处可见变化**（相对旧 `LockPitch`）：笔刷端点按插值精确落在刷到的位置（原来只取范围内原始点、
  端点会缩进）；锚点数经 `Simplify(5,2)` 变少（与手绘同口径）。

## 七、如实性边界（回归项，确认不被"矫正"）

### 21. 量程不一致 = 显示错位，不报错不钳位
- 口径：宿主对配对的两条轨**各按自己量程**投影。若作者把回显声明成 0..100、实参轨声明成 0..1，
  固定出的锚点值（真实数值，如 50）会落在实参轨量程外，曲线画出界。
- 预期：**不弹错误、不打断操作、不把值钳进量程**（钳位会静默改数据）。这是作者的声明责任。

### 22. 换 tempo 后固定结果不跟随
- 固定一段实参轨 → 改工程 tempo。
- 预期：实参轨锚点留在原 tick 位置（秒→tick 换算已固化），与手画曲线同待遇；回显（秒域）则随 tempo 移动，
  二者分离是**预期**行为。

### 23. effect / instrument 的分段轨也生效（三侧接线补齐）
- **effect**：给 part 挂一个声明了可编辑分段轨的 effect（如 `V1.Effect` 若有），在该轨上画一笔。
- 预期：**立即**触发该 effect 重新处理（曲线一改就重算），而不是"改了没反应、动一下别的参数才生效"。
- **instrument**：给 instrument part 的分段轨画一笔。
- 预期：引擎读到的是**用户画的值**（此前恒取 NaN，画了完全没效果），且改动立即触发重合成。
- 若手边没有声明分段轨的 effect / instrument 夹具，记 N/A —— 这两侧目前无夹具覆盖。

### 24. 存盘往返
- 固定后保存工程、重开。
- 预期：实参轨曲线原样恢复（它就是普通 automation 数据，走既有序列化）；回显不入工程文件、需重新合成才出现。
